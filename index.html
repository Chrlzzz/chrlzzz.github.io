Analog Communications
AM · FM · PM · Transmitters · Receivers
AM — Amplitude Modulation
s(t) = Ac[1 + ma·cos(2πfmt)] · cos(2πfct)
  • mₐModulation index = Am/Ac (0 ≤ mₐ ≤ 1 for no overmod.)
  • BW= 2fm (DSB) or fm (SSB)
  • Pt= Pc(1 + mₐ²/2) — total DSB-LC power
  • η= mₐ²/(2 + mₐ²) — power efficiency
⚠ Key Fact At mₐ = 1 (100% modulation), efficiency is only 33.3%. Max sidebands = (mₐ²/4)·Pc each.
AM Variants — DSB, SSB, VSB
TypeBWCarrierUse
DSB-LC2WTransmittedBroadcast AM
DSB-SC2WSuppressedEfficient, needs sync
SSB-SCWSuppressedHF voice, most efficient
VSB~1.25WPartialTV video (NTSC)

W = message bandwidth

FM — Frequency Modulation
s(t) = Ac·cos[2πfct + β·sin(2πfmt)]
  • β= Δf/fm = kf·Am/fm (modulation index)
  • Δf= kf·Am — max frequency deviation
  • CarsonBW ≈ 2(Δf + fm) = 2fm(β+1)
  • SNRFM= 3β²(β+1)·SNRbaseband
💡 Remember Broadcast FM: Δf = ±75 kHz, fm = 15 kHz → β = 5, BW = 180 kHz
PM — Phase Modulation
s(t) = Ac·cos[2πfct + kp·m(t)]
  • kpPhase sensitivity (rad/V)
  • Δφ= kp·Am — max phase deviation
  • vs FMPM β depends on Am; FM β depends on fm
📌 FM vs PM FM: constant Δf regardless of fm. PM: β = kp·Am (independent of fm). You can make FM from PM by pre-integrating m(t).
AM Spectra

DSB-LC spectrum has 3 components:

  • Carrier: at fc, power = Ac²/2
  • USB: at fc + fm, power = (mₐAc/2)²/2
  • LSB: at fc − fm, power = (mₐAc/2)²/2
PUSB = PLSB = (mₐ²/4)·Pc
FM Spectra — Bessel Functions

FM has theoretically infinite sidebands. The nth sideband pair has amplitude Jn(β):

s(t) = Ac Σ Jn(β) cos[2π(fc+nfm)t]
  • RuleSidebands significant if |Jn(β)| > 0.01
  • β≪1Narrowband FM ≈ AM-like (2 sidebands)
  • β≫1Wideband FM — many sidebands
Superheterodyne Receiver

Standard AM/FM receiver architecture:

  • RF Amp → Mixer → IF Filter → Detector → Audio Amp
  • AM IF = 455 kHz; FM IF = 10.7 MHz
  • Image frequency: fimage = fs + 2·fIF
  • Image rejection ratio (IRR) depends on pre-selector Q
fLO = fs + fIF (high-side injection)
AM Demodulation
  • EnvelopeDiode + RC filter. Simple, no sync needed. RC ≈ 1/(2πfm)
  • Sync DetMultiply by local carrier, LPF. Used for DSB-SC, SSB
  • SquaringSquare signal, BPF at 2fc, divide by 2 → carrier recovery

FM Demodulation

  • Limiter-DiscFoster-Seeley discriminator — most common
  • PLLPhase-locked loop — excellent noise performance
  • Ratio DetBalanced discriminator, amplitude insensitive

Information Theory & Random Processes
Entropy · Channel Capacity · Noise · PSD
Self-Information & Entropy
I(xi) = log2(1/P(xi)) = −log2P(xi) [bits]
H(X) = −Σ P(xi) · log2 P(xi) [bits/symbol]
  • Max HHmax = log2(M) when all symbols equiprobable
  • Unitslog2→bits, loge→nats, log10→Hartleys
  • H(X,Y)= H(X) + H(Y|X) — chain rule
📌 QuickEntropy for binary source: H = −p·log p − (1−p)·log(1−p); maximum at p=0.5 → H=1 bit
Mutual Information & Channel Capacity
I(X;Y) = H(X) − H(X|Y) = H(Y) − H(Y|X)
C = B · log2(1 + S/N) [bps] ← Shannon-Hartley
  • BChannel bandwidth [Hz]
  • S/NSignal-to-noise ratio (linear, not dB!)
  • NyquistC = 2B·log2(M) — noiseless, M levels
💡Doubling BW < doubling SNR for high SNR — BW is more efficient.
Source Coding Theorems
  • Shannon 1stAverage code length L̄ ≥ H(X); can approach H(X) arbitrarily close
  • HuffmanOptimal prefix-free code. Assign shorter codes to probable symbols
  • Efficiencyη = H(X) / L̄ × 100%
  • RedundancyR = 1 − η
Channel Coding — Shannon 2nd Theorem

If R < C, there exists a code that achieves arbitrarily low error probability.

  • Hamming distdmin = min distance between codewords
  • Error detectDetects up to dmin − 1 errors
  • Error correctCorrects up to ⌊(dmin−1)/2⌋ errors
  • Hamming code(2r−1, 2r−1−r), dmin=3; r = parity bits
Random Processes & Autocorrelation
RX(τ) = E[X(t)·X(t+τ)]
  • RX(0)= E[X²] = Total power
  • RX(τ)= RX(−τ) — even function
  • WSSWide-sense stationary: mean constant, R depends only on τ
  • ErgodicTime avg = ensemble avg for any realization
Power Spectral Density (PSD)
SX(f) = ℱ{RX(τ)} [Wiener-Khinchin theorem]
PX = ∫-∞∞ SX(f) df = RX(0)
  • White noiseSN(f) = N₀/2 — flat PSD (all freqs)
  • FilteredSY(f) = |H(f)|² · SX(f)
  • BandwidthNoise BW BN = ∫|H|²df / |H|²max
Noise & dB Calculations
NF [dB] = 10·log10(F) where F = SNRin/SNRout
Ftotal = F₁ + (F₂−1)/G₁ + (F₃−1)/(G₁G₂) + ... [Friis]
  • k= 1.38×10⁻²³ J/K (Boltzmann's constant)
  • N= kTB — thermal noise power
  • T = 290KN = −174 dBm/Hz (standard reference)
  • dBm= 10·log10(PmW) → 1W = +30 dBm

Digital Communications
Sampling · PCM · Digital Modulation · TDMA/FDMA/CDMA · BER/SNR
Sampling Theorem
fs ≥ 2·fmax [Nyquist-Shannon]
  • Nyquist ratefN = 2·fmax — minimum sampling rate
  • AliasingOccurs when fs < 2fmax — frequency foldover
  • Anti-aliasLPF before sampler to band-limit signal
  • Voicefmax=4kHz → fs=8kHz → 8000 samples/s
Quantization & PCM
Δ = (Vmax−Vmin) / 2n — step size
SQNR ≈ 1.76 + 6.02·n [dB] — approx per bit
  • nNumber of bits per sample
  • L= 2n quantization levels
  • Rb= n · fs bits/s — PCM bit rate
  • BWPCM≥ n·fs/2 Hz (Nyquist signaling)
📌 PCM Voice8-bit, 8kHz → 64 kbps (one DS0 channel)
Companding — µ-law & A-law
µ-law: F(x) = sgn(x)·ln(1+µ|x|)/ln(1+µ) [µ=255, North America/Japan]
A-law: used in Europe (A=87.6), ITU-T G.711

Companding = COMPressing + exPANDING. Improves SNR for low-level signals.

DPCM & Delta Modulation
  • DPCMEncode difference between sample and prediction; reduces bit rate
  • ADPCMAdaptive DPCM — variable step size (G.726: 32 kbps)
  • DM1-bit DPCM; slope overload & granular noise are key distortions
  • ADMAdaptive DM — varies step size to reduce both distortions

ISI, BER, SNR & Matched Filter
  • ISIInter-symbol interference — dispersion/multipath. Eye diagram shows ISI.
  • Nyquist ISIZero ISI if pulse spectrum is Nyquist: raised cosine filter
  • Matched filterMaximizes SNR at sampling instant; H(f)=S*(f)·e^(−j2πft₀)
  • SNRmax= 2E/N₀ at matched filter output
  • BER BPSKPe = Q(√(2Eb/N₀)) — best for PSK
  • Q functionQ(x) = (1/2)erfc(x/√2) ≈ e^(−x²/2)/(x√(2π))
💡 Eye DiagramWide-open eye = low ISI. Eye closure = high ISI. Optimal sampling at center of eye opening.

Transmission Lines & Optical Fibers
TL Equations · Impedance · S-params · Smith Chart · Waveguides · Fiber
Transmission Line Equations
Z₀ = √((R+jωL)/(G+jωC)) [characteristic impedance]
γ = α + jβ = √((R+jωL)(G+jωC)) [propagation constant]
  • LosslessR=G=0 → Z₀=√(L/C), β=ω√(LC), α=0
  • vp= ω/β = 1/√(LC) = c/√(εrμr)
  • λ= vp/f = 2π/β
Reflection & Impedance Transformation
Γ = (ZL−Z₀)/(ZL+Z₀) [reflection coefficient]
Zin = Z₀·(ZL+jZ₀·tan(βl))/(Z₀+jZL·tan(βl))
  • SWR= (1+|Γ|)/(1−|Γ|) ≥ 1. Perfect match: SWR=1
  • λ/4Zin = Z₀²/ZL (quarter-wave transformer)
  • λ/2Zin = ZL (half-wave — repeats load)
  • Short SCΓ=−1, ZL=0 → Zin=jZ₀tan(βl)
  • Open OCΓ=+1, ZL=∞ → Zin=−jZ₀cot(βl)
S-Parameters
ParameterMeaningNotes
S₁₁Input reflectionReturn loss = −20log|S₁₁|
S₂₁Forward gain/lossInsertion loss = −20log|S₂₁|
S₁₂Reverse isolationS₁₂=S₂₁ for reciprocal
S₂₂Output reflectionLike S₁₁ at port 2
RememberPassive lossless: |S₁₁|²+|S₂₁|²=1 (power conservation). Perfectly matched: S₁₁=S₂₂=0.
Smith Chart Essentials
  • CenterZ₀ (normalized z=1+j0) — perfect match point
  • CirclesConstant resistance circles (r=const), reactance arcs
  • RotationMoving toward generator (source) = clockwise; toward load = CCW
  • Full turnOne revolution = λ/2 along line
  • AdmittanceRotate 180° on Smith chart to get Y from Z
Matching TechniqueAdd shunt stub or series element. Stub = short/open TL of length l to cancel reactance.
Rectangular Waveguides
fc,mn = (c/2)·√((m/a)²+(n/b)²) [cutoff frequency]
  • TE₁₀Dominant mode (lowest fc); fc = c/2a for a>b
  • No TEMWaveguides don't support TEM mode (no two conductors)
  • λg= λ₀/√(1−(fc/f)²) — guide wavelength
  • vg= c·√(1−(fc/f)²) — group velocity < c
  • vp= c/√(1−(fc/f)²) — phase velocity > c
Optical Fiber
  • NA= √(n₁²−n₂²) = n₁·√(2Δ) — numerical aperture
  • θc= sin⁻¹(NA) — acceptance cone half-angle
  • TIRTotal internal reflection at n₁/n₂ interface (n₁>n₂)
  • SMFSingle-mode: core ≈ 9µm, no modal dispersion, long-haul
  • MMFMulti-mode: core ≈ 50/62.5µm, modal dispersion, shorter reach

Fiber Loss

α [dB/km] = (10/L)·log10(Pin/Pout)

1310nm window: ~0.35 dB/km | 1550nm window: ~0.2 dB/km (lowest attenuation)

Wave Propagation & Antenna Theory
EM Waves · Polarization · Dipoles · Arrays · Antenna Parameters
EM Wave Fundamentals
c = f·λ = 3×10⁸ m/s [free space]
v = c/√(εrμr) [in medium]
  • η₀= 377 Ω — free space intrinsic impedance (√(μ₀/ε₀))
  • η= η₀/√(εr) in lossless non-magnetic medium
  • PoyntingS⃗ = E⃗ × H⃗ [W/m²] — power density vector
Reflection, Refraction, Polarization
  • Snell'sn₁·sin θ₁ = n₂·sin θ₂ (refraction)
  • BrewsterθB = tan⁻¹(n₂/n₁) — no reflection for TM polarization
  • Criticalθc = sin⁻¹(n₂/n₁) for n₁>n₂ — total internal reflection
  • Linear polE in fixed plane; Circular pol: |Ex|=|Ey|, 90° phase diff
Skin Depthδ = 1/√(πfμσ) — depth at which E decays to e⁻¹ = 36.8%. Higher freq = shallower depth.

Dipole & Monopole Antennas
  • HertzianInfinitesimal dipole (Δl≪λ). Directivity D=1.5 (1.76 dBi)
  • Half-waveλ/2 dipole: D=1.64 (2.15 dBi), Rrad=73.1Ω
  • Quarter-waveλ/4 monopole over ground: D=3.28 (5.15 dBi), Rrad=36.5Ω
  • PatternDipole: toroidal (donut), null at tips, max broadside
Key Antenna Parameters
G = D · ηa [Gain = Directivity × Efficiency]
Aeff = G·λ²/(4π) [effective aperture]
  • HPBWHalf-power beam width — at −3dB points
  • FNBWFirst null beam width ≈ 2×HPBW (approx)
  • F/B ratioForward-to-back gain ratio [dB]
  • dBd vs dBidBi = dBd + 2.15 (isotropic vs half-wave dipole reference)
Friis Transmission & Link Budget
Pr/Pt = Gt·Gr·(λ/4πd)² [Friis equation]
FSPL [dB] = 20·log(d) + 20·log(f) + 20·log(4π/c) ≈ 32.44 + 20log(fMHz) + 20log(dkm)
  • Link budgetEIRP − path loss − system losses + Gr ≥ Rx sensitivity
  • EIRP= Pt·Gt [W] or Pt[dBW] + Gt[dBi]
Linear Antenna Arrays
AF = Σ an·ejnψ where ψ = βd·cosθ + δ
  • Broadsideδ=0, max at θ=90° (perpendicular to array)
  • End-fireδ=±βd, max along array axis
  • N elementsDirectivity ≈ 2N (broadside uniform array)
  • Grating lobesOccur when d ≥ λ; avoid with d ≤ λ/2

OFDM — Key Concepts
Subcarrier spacing Δf = 1/Ts; subcarriers orthogonal
  • Cyclic prefixCopies end of symbol to beginning — eliminates ISI in multipath
  • CP lengthMust be ≥ max channel delay spread
  • PAPRHigh Peak-to-Average Power Ratio — main disadvantage of OFDM
  • DFT/IDFTModulation via IFFT, demodulation via FFT
  • 4G vs 5GLTE: Δf=15kHz. 5G NR: scalable numerology (15kHz to 240kHz)
Cellular Concepts
  • HandoffHard: break-before-make. Soft (CDMA): make-before-break.
  • Frequency reuseD/R = √(3N); N = cluster size; typical N=7 (2G)
  • Cell splittingDivide cells to increase capacity; smaller radius = more users
  • Sectorization120° sectors × 3 = 3-sector cell; reduces co-channel interference
  • FadingLarge-scale (path loss/shadowing) vs small-scale (multipath/Doppler)
  • Rayleigh fadingNo LOS component; Rician: with LOS component (K-factor)
